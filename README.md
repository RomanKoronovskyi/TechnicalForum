# TechnicalForum

Контейнеризована, захищена вебплатформа технічних запитань та відповідей, розроблена для обміну знаннями між розробниками, оцінювання корисних рішень та отримання миттєвої експертної допомоги від штучного інтелекту.

## Технологічний стек

- **Бекенд-фреймворк:** Django (Python 3.13)
- **База даних:** PostgreSQL 15
- **WSGI HTTP-сервер:** Gunicorn
- **Зворотний проксі-сервер:** Nginx (із підтримкою SSL/TLS)
- **Інтеграція ШІ:** Google Gemini API (`gemini-2.5-flash` через сучасний SDK `google-genai`)
- **Інфраструктура:** Docker & Docker Compose
- **Автоматизоване тестування:** Django TestCase (Unit-тести)

---

## Архітектура та ключові особливості

- **Модульне розмежування:** Логіку платформи розділено на два ізольовані застосунки: `users` (керування акаунтами, профілями та репутацією) та `forum` (запитання, відповіді, тегування, голосування та сповіщення).
- **Асинхронний ШІ-агент:** Під час публікації розробником нового запитання, ізольований фоновий потік (`threading.Thread`) ініціює запит до Gemini API. ШІ аналізує проблему та автоматично генерує точне технічне рішення за кілька секунд, взагалі не блокуючи основний HTTP-цикл «запит-відповідь» вебсервера.
- **Комплексна безпека:** Повний захист від SQL-ін'єкцій на рівні Django ORM та захист від міжсайтової підробки запитів (CSRF) за допомогою токенів. Абсолютна ізоляція секретів системи (паролів БД та ключів ШІ) у локальному файлі `.env`.
- **Шифрування трафіку:** Вебсервер Nginx виступає єдиною точкою входу, забезпечуючи примусове перенаправлення з HTTP на захищений протокол HTTPS (`301 Redirect`) та максимально швидку роздачу статичних файлів (CSS, JS, зображення) безпосередньо з диска.
